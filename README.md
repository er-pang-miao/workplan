# Work Plan Chrome Extension

一个用于管理工作计划的Chrome浏览器扩展。

## 概述

Work Plan是一个轻量级的工作计划管理工具，以Chrome扩展的形式提供便捷的任务管理功能。用户可以通过这个扩展快速记录、查看和管理工作中的计划任务。

## 功能特性

- 快速访问：通过浏览器按钮快速打开工作计划界面
- 简洁界面：直观的用户界面设计
- 便捷管理：轻松添加、编辑和跟踪工作计划

## 安装方法

1. 下载此扩展程序文件
2. 打开Chrome浏览器，进入 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择扩展程序所在的文件夹

## 使用说明

1. 点击浏览器工具栏中的工作计划图标
2. 在弹出的界面中可以查看和管理工作计划
3. 添加新的工作任务并设置相关属性

## 技术细节

- Manifest版本：2
- 图标：assets/images/plan.png
- 背景页面：background.html
- 弹出页面：popup.html
